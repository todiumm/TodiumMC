# Todium Behavior Packs

Coloque aqui seus Behavior Packs do Minecraft Bedrock.

O Todium procura:
- pastas contendo `manifest.json`
- arquivos `.mcpack`
- arquivos `.mcaddon`
- arquivos `.zip`

O diretório padrão é `behavior_pack/`.

O `TodiumExample/` é um exemplo mínimo para testar a descoberta e o carregamento nativo. O item de exemplo precisa de um Resource Pack com a textura `todium_ruby` para aparecer corretamente no cliente.
